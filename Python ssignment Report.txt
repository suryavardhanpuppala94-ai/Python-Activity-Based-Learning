Case 86: Multi-Stage ATM Transaction Audit
1. Problem Statement
Process a sequence of deposits and withdrawals, update an account balance, reject invalid withdrawals, and show the
final balance.
2. Objectives
Use tuples, tuple unpacking, loops, conditions, and arithmetic operators.
3. Assumptions
Transactions are represented as (type, amount). D means deposit and W means withdrawal. Starting balance is n1,000.
4. Algorithm
1. Set the starting balance to 1000.
2. Read each transaction tuple and unpack its type and amount.
3. For a valid positive deposit, add the amount.
4. For a withdrawal, subtract only if the amount is positive and does not exceed the balance.
5. Report invalid transactions and print the final balance.
5. Pseudocode
START
balance ‹ 1000
FOR each (type, amount) in transactions
  IF amount <= 0: report invalid
  ELSE IF type = D: add amount
  ELSE IF type = W AND amount <= balance: subtract amount
  ELSE IF type = W: report insufficient balance
  ELSE: report unknown transaction
PRINT balance
STOP
6. Python Source Code
balance = 1000
transactions = [("D", 500), ("W", 200), ("W", 2000), ("X", 100), ("D", 300)]
for transaction in transactions:
    transaction_type, amount = transaction
    print(transaction_type, amount, end=": ")
    if amount <= 0:
        print("Invalid amount")
    elif transaction_type == "D":
        balance = balance + amount
        print("Deposit accepted")
    elif transaction_type == "W":
        if amount <= balance:
            balance = balance - amount
            print("Withdrawal accepted")
        else:
            print("Insufficient balance")
    else:
        print("Invalid transaction type")
print("Final balance: Rs.", balance)

2. Objectives
Use tuples, lists, loops, eligibility conditions, and simple sorting.
3. Assumptions
Eligibility requires academic marks of at least 60 and attendance of at least 75%. Combined score is marks plus
assessment score. Higher combined score ranks first.
4. Algorithm
1. Store each candidate as a tuple of name, marks, assessment, and attendance.
2. Keep only candidates who meet both eligibility conditions.
3. Calculate each eligible candidate's combined score.
4. Sort eligible candidates by score from highest to lowest using nested loops.
5. Display the ranking.
5. Pseudocode
START
Create candidate list
Create empty eligible list
FOR each candidate
  IF marks >= 60 AND attendance >= 75: add candidate with combined score
FOR each pair of eligible candidates
  IF earlier score < later score: swap them
Display ranked list
STOP
6. Python Source Code
candidates = [
    ("Anu", 82, 14, 90),
    ("Ravi", 75, 18, 80),
    ("Meena", 55, 20, 92),
    ("Kiran", 88, 10, 78)
]
eligible = []
for name, marks, assessment, attendance in candidates:
    if marks >= 60 and attendance >= 75:
        eligible.append((name, marks, assessment, attendance, marks + assessment))
for i in range(len(eligible)):
    for j in range(i + 1, len(eligible)):
        if eligible[j][4] > eligible[i][4]:
            eligible[i], eligible[j] = eligible[j], eligible[i]
rank = 1
for name, marks, assessment, attendance, score in eligible:
    print(rank, name, "Combined score:", score)
    rank = rank + 1

Case 65: Campus Resource Allocation Under Constraints
1. Problem Statement
Compare required equipment with available quantities and report how much can be allocated and what shortage remains.
2. Objectives
Use nested lists, arithmetic, loops, and conditional statements.
3. Assumptions
Each activity receives up to its requested quantity. Available stock cannot be exceeded. Activities are processed in the
listed priority order.
4. Algorithm
1. Store activity, available quantity, and required quantity in a nested list.
2. For each activity, allocate the smaller of available and required quantities.
3. Calculate the shortage as required minus allocated.
4. Display allocation and shortage.
5. Pseudocode
START
FOR each activity, available, required
  IF available < required: allocated ‹ available
  ELSE: allocated ‹ required
  shortage ‹ required - allocated
  PRINT activity, allocated, shortage
STOP
6. Python Source Code
resources = [
    ["Robotics club", 8, 6],
    ["Science fair", 5, 7],
    ["Coding event", 10, 10],
    ["Art club", 2, 4]
]
for resource in resources:
    activity, available, required = resource
    if available < required:
        allocated = available
    else:
        allocated = required
    shortage = required - allocated
    print(activity, "| Allocated:", allocated, "| Shortage:", shortage)

5. Pseudocode
START

6. Python Source Code
students = ["Anu", "Ravi", "Meena", "Kiran", "Divya", "Arjun", "Sara"]
capacities = [2, 3, 1]
student_index = 0
room_number = 1
for capacity in capacities:
    print("Room", room_number, ":")
    assigned = 0
    while assigned < capacity and student_index < len(students):
        print(" ", students[student_index])
        student_index = student_index + 1
        assigned = assigned + 1
    room_number = room_number + 1
if student_index < len(students):
    print("Unallocated students:")
    for i in range(student_index, len(students)):
        print(students[i])
else:
    print("All students allocated")

Case 79: Integrated Warehouse Order Prioritization
1. Problem Statement
Compare product stock with requested order quantities, process high-priority orders first, and calculate fulfilled and
outstanding quantities.
2. Objectives
Practise tuples, tuple unpacking, list sorting, loops, and conditional logic.
3. Assumptions
Priority 1 is highest. Each record contains product, stock, order quantity, and priority. Stock is allocated in priority order and
cannot become negative.
4. Algorithm
1. Store product records as tuples.
2. Sort records by priority number, with smaller numbers first.
3. For each order, fulfill the smaller of stock and requested quantity.
4. Calculate the outstanding quantity.
5. Display the fulfillment report.
5. Pseudocode
START
Store orders as tuples
Sort orders by priority ascending
FOR each product, stock, requested, priority
  fulfilled ‹ smaller of stock and requested
  outstanding ‹ requested - fulfilled
  PRINT fulfillment report
STOP
6. Python Source Code
orders = [
    ("Pens", 50, 30, 2),
    ("Notebooks", 20, 35, 1),
    ("Folders", 40, 15, 3)
]
for i in range(len(orders)):
    for j in range(i + 1, len(orders)):
        if orders[j][3] < orders[i][3]:
            orders[i], orders[j] = orders[j], orders[i]
for product, stock, requested, priority in orders:
    if stock < requested:
        fulfilled = stock
    else:
        fulfilled = requested
    outstanding = requested - fulfilled
    print(product, "| Priority:", priority,
          "| Fulfilled:", fulfilled,
          "| Outstanding:", outstanding)
