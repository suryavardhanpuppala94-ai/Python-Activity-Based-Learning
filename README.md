Python ABL Assignment

About the Project

This repository contains my Python ABL (Activity-Based Learning) Assignment. It includes Python programs designed to demonstrate fundamental programming concepts and problem-solving skills using Python.

Objectives

- Understand basic Python programming concepts.
- Develop logical thinking and problem-solving skills.
- Practice writing, executing, and testing Python programs.
- Understand program outputs through sample results.

Project Contents

- Python source files: 10 Python programs.
- Assignment Report: PDF report containing the assignment details and programs.
- Output Screenshots: Images showing the outputs of the programs.
- Test Run Summary: Summary of program execution and testing.

Technologies Used

- Python 3
- Visual Studio Code or any Python-compatible code editor

How to Run the Programs

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in your code editor.
4. Open the Python file you want to execute.
5. Run the program and provide the required input, if prompted.
6. Check the output displayed in the terminal.

Run Using the Terminal

python3 filename.py

Replace "filename.py" with the name of the Python program you want to execute.

Testing

The Python programs are intended to be executed and tested with appropriate inputs to verify their outputs. Refer to the output screenshots and test-run summary included in this repository.
